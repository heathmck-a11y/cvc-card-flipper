# CVC Card Flipper

Three letter cards that make nonsense CVC words for reading practice. It runs in the browser with no login.

- Tap any card to flip it to a new letter, or press New word for a whole new word
- Choose which letters to use for the first, middle, and last card
- Option to keep the last card face down until it is tapped
- A 10-word game that keeps a score for a group or a student by day
- Real words are skipped, so only nonsense words come up

Scores and settings are saved in the browser on the device where the app is used.

To publish with GitHub Pages, go to Settings, then Pages. Under Branch, choose `main`, then `/ (root)`, and save. The app will be at https://heathmck-a11y.github.io/cvc-card-flipper/
